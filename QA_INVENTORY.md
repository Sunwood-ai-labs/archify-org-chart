# Publication QA

Scope: finish the existing Antigravity organization chart and avatar work, make
the repository reproducible, verify the published site, commit and push.

## Deliverables and checks

- CLI: fresh engine setup, custom/starter builds, safe output paths, explicit
  failure without the engine, validated configuration and reporting lines.
- Avatars and board: all members present, embedded images, keyboard interaction,
  identical behavior in automated and ordinary browsers, responsive layout.
- Public demos: regenerate both examples and copy the exact outputs to Pages.
- Documentation: English/Japanese setup, actual supported layout limits,
  avatar provenance, contribution steps, dependency/license attribution.
- Automation: reproducible installs, CLI regression tests, docs build and Pages.
- Final verification: local tests/build, browser review, deployed HTTP responses,
  successful GitHub Actions, remote HEAD matching the local commit, clean tree.

Results will be recorded in `docs/verification.md` with the final checked scope.
